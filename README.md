# phishing-investigationn

## Objective
Investigate a simulated phishing email and identify signs of phishing.

## Findings
- The email uses urgent language.
- The sender address looks suspicious.
- The email asks the user to click a link.
- The email uses a generic greeting: "Dear Customer"

  ## Conclusion
The simulated email contains several common phishing indicators, including urgency, a suspicious sender, a verification link, and a generic greeting.
